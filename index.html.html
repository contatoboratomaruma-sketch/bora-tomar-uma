☁️ Para sincronizar entre aparelhos: crie conta gratuita em supabase.com, crie um projeto, copie URL e chave anon em Project Settings → API.

📋 Execute este SQL no SQL Editor do Supabase: CREATE TABLE produtos (id BIGSERIAL PRIMARY KEY, nome TEXT, cat TEXT, codigo TEXT, qtd INT, minimo INT, preco_venda NUMERIC, preco_compra NUMERIC, unit TEXT, created_at TIMESTAMPTZ DEFAULT NOW()); CREATE TABLE movimentacoes (id BIGSERIAL PRIMARY KEY, tipo TEXT, descricao TEXT, valor NUMERIC, codigo TEXT, ts TIMESTAMPTZ DEFAULT NOW()); CREATE TABLE vendas (id BIGSERIAL PRIMARY KEY, prod_id INT, nome TEXT, cat TEXT, qtd INT, receita NUMERIC); CREATE TABLE feedbacks (id BIGSERIAL PRIMARY KEY, nome TEXT, stars INT, texto TEXT, ts TIMESTAMPTZ DEFAULT NOW()); ALTER TABLE produtos ENABLE ROW LEVEL SECURITY; ALTER TABLE movimentacoes ENABLE ROW LEVEL SECURITY; ALTER TABLE vendas ENABLE ROW LEVEL SECURITY; ALTER TABLE feedbacks ENABLE ROW LEVEL SECURITY; CREATE POLICY "all" ON produtos FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "all" ON movimentacoes FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "all" ON vendas FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "all" ON feedbacks FOR ALL USING (true) WITH CHECK (true);
